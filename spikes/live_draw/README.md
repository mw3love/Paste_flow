## 판정

- 파이썬 + PyQt6 그대로 간다. Qt 안의 줄이기(선 굳히기 등)도 지금은 필요 없다.
- 가짜 이벤트라 운영체제 입력 지연·화면 갱신 주기(모니터 Hz)는 안 들어갔다 — 손맛은 사람이 본다(계획 4칸 눈 행).
- 4K·배율 150% 이상 모니터는 이 PC에 없어 못 쟀다 — 다른 PC에서 `--auto`로 확인할 것.
