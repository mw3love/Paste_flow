# 판서 툴바에 닫기 버튼(Ctrl+Shift+D)

상태: 초안
만든 날: 2026-11-28 21:31

## 지금 무엇이 불편한가

판서를 끄려면 단축키나 Esc를 알아야 한다. 툴바에서 바로 끌 수 없다.

## 원하는 동작

판서 툴바에 닫기 버튼. 툴팁에 단축키(Ctrl+Shift+D, 설정값을 따름). 누르면 단축키로 끈 것과 같다(빈 칠판으로 숨김, Ctrl+Z로 되살림).

## 어떻게 되면 끝인가

버튼을 누르면 판서가 꺼지고, 다시 켜면 빈 칠판이다.

(안 들음)

## 정해 둔 것 · 모르는 것

자리(맨 오른쪽? 앱 쓰기 옆?)와 그림은 모름.
