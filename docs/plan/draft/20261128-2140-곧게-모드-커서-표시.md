# 곧게(직선) 모드일 때 커서에 표시

상태: 초안
만든 날: 2026-11-28 21:40

## 지금 무엇이 불편한가

Shift를 누르거나 곧게 잠금이 켜져 직선 모드인지가 툴바 아이콘으로만 보인다. 그릴 때 눈은 커서에 있다.

## 원하는 동작

곧게일 때(Shift 누름 또는 잠금, 펜·형광펜·사라지는 펜) 커서 모양이나 색이 바뀐다(사용자 제안). Claude 추천: 커서 옆 작은 직선 그림(색만 바꾸면 화면 배경·펜 색과 섞임).

## 어떻게 되면 끝인가

Shift를 누르는 동안과 잠금 동안 커서가 바뀌고, 떼거나 풀면 돌아온다. 판서·미리보기 편집 둘 다.

## 하지 않는 것

(안 들음)

## 정해 둔 것 · 모르는 것

모양과 색 중 무엇으로 할지는 사용자가 아직 안 정함. 신호는 툴바 아이콘과 같은 set_shift_held·set_straight_lock을 쓰면 된다. 지금 펜 커서 모양은 확인 필요.
