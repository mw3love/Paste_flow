# 도구 옵션창이 위에 자리가 없으면 아래로 뒤집어 뜬다 — 툴바를 가리지 않게

상태: 준비됨
만든 날: 2026-11-28
고친 날: 2026-11-28
기준: 34c944f

판서 툴바를 손잡이로 화면 맨 위로 옮긴 뒤 도구 옵션창(색·두께 말풍선)을 열면 옵션창이 툴바를 가린다. 옵션창이 늘 버튼 위에 뜨고, 자리가 없으면 화면 안으로 밀어 넣기만 하기 때문이다. 초안: `docs/plan/draft/20261128-2134-툴바-끝에서-옵션창-자리.md`.

## 0. 확정된 결정

| 결정 | 정한 것 | 버린 안 | 근거 |
|---|---|---|---|
| 자리가 없을 때 | 버튼(또는 그림) 위에 옵션창 높이만큼 자리가 없으면 아래로 뒤집어 띄운다 — 버튼 아래 2px, 꼬리는 위를 가리킨다. 가로는 지금처럼 화면 안으로 밀고 꼬리는 버튼 쪽 | 밀어 넣기만(지금 — 툴바를 가림) | Claude가 정함(사용자 요구 「반응형」) |
| 그림 우클릭 옵션창 | 같은 규칙 — 그림 위에 자리가 없으면 그림 아래쪽 가운데를 가리키며 아래에 뜬다 | 버튼만 고치기 | Claude가 정함 |
| 판정 자리 | 위·아래를 고르는 계산을 순수 함수 `_popup_y(anchor_top, anchor_bottom, pop_h, avail_top, avail_bottom)` → (y, 꼬리 위인가)로 떼어 시험 | 열기 함수 안에 if문 | Claude가 정함 · 같은 파일 `_tail_offset` 선례 |

## 1. 지금 상태

- 옵션창 열기 `_EditorMixin._open_tool_settings(tool_key, btn, anchor=None)`(`pasteflow/ui/image_annotator.py`): y = 버튼(또는 anchor) 위 − 옵션창 높이 − 2, 그다음 화면 사용 영역 안으로 자른다. 그래서 위에 자리가 없으면 옵션창이 버튼 위에 겹친다.
- 옵션창 `_ToolSettingsPopup`(`pasteflow/ui/image_annotator.py:2762`)은 `paintEvent`에서 말풍선과 **아래쪽** 꼬리만 그린다. 꼬리 높이 `_POP_TAIL`(`pasteflow/ui/image_annotator.py:2659`), 여백은 `_build_tool_settings_popup`의 `col.setContentsMargins(10, 8, 10, 8 + _POP_TAIL)` — 꼬리 자리가 아래에만 있다.
- 꼬리 가로 자리 `_tail_offset`(시험 `tests/test_annotator_tools.py`의 `test_tail_offset_points_at_button`).
- 그림 우클릭은 `open_item_settings`가 그림 위쪽 가운데를 anchor로 넘긴다.

## 2. 원하는 동작

1. 판서 툴바를 화면 맨 위로 옮기고 펜 버튼을 우클릭 → 옵션창이 툴바 **아래**에 뜨고 꼬리가 위로 펜 버튼을 가리킨다. 툴바가 가려지지 않는다.
2. 툴바가 아래(기본 자리)면 지금처럼 위에 뜨고 꼬리는 아래.
3. 미리보기 편집기도 같다(창이 화면 위 끝에 붙어 있으면 아래로).
4. 그림 우클릭: 그림이 화면 위 끝이면 그림 아래에 뜨고 꼬리는 그림 아래쪽 가운데를 가리킨다.
5. 다시 열 때마다 그때 자리로 판정한다(뒤집힌 채 남지 않음).
