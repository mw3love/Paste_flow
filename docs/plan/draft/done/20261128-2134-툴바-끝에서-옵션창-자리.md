# 툴바를 화면 위·아래 끝에 두면 도구 옵션창이 툴바를 가림

상태: 초안
만든 날: 2026-11-28 21:34

## 지금 무엇이 불편한가

판서 툴바를 손잡이로 화면 맨 위(또는 맨 아래)로 옮긴 뒤 도구 옵션창(우클릭 미니패널)을 열면, 옵션창이 툴바를 가린다. 지금 옵션창은 늘 버튼 위에 뜨고 자리가 없으면 화면 안으로 밀기만 한다(꼬리도 늘 아래).

## 원하는 동작

버튼 위에 자리가 없으면 버튼 아래로 뒤집어 뜨고 꼬리도 위를 가리킨다(반응형). 툴바를 가리지 않는다.

## 어떻게 되면 끝인가

툴바를 맨 위·맨 아래에 두고 각 도구 옵션창을 열어도 툴바가 안 가려진다.
