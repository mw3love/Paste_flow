판서 툴바가 작고(아이콘 18px — 미리보기 편집기와 같은 공용 툴바), 손잡이로 옮긴 자리를 다음에 켤 때 잊고, 앱 쓰기 상태의 연필 아이콘이 화면을 계속 가린다. 셋을 다듬는다. 초안: `docs/plan/draft/20261128-2135-판서-툴바-크기와-자체-개선-검토.md`.

## 0. 확정된 결정

| 결정 | 정한 것 | 버린 안 | 근거 |
|---|---|---|---|
| 아이콘 크기 | 판서만 22px. 공용 툴바에 클래스 값 `_toolbar_icon_px = 18`을 두고 판서 창(`LiveDrawOverlay`)이 22로 바꾼다. 미리보기 편집기는 18 그대로. 판서의 앱 쓰기·닫기 버튼도 같은 값 | 둘 다 키우기(작은 이미지 창에서 툴바가 창보다 넓어짐) · 그대로 | 물어서 정함 · 공용 툴바 `QSize(18, 18)` 7곳(`pasteflow/ui/image_annotator.py`) · 선례 `_allow_fade_pen` |
| 툴바 자리 기억 | 손잡이로 옮기고 놓을 때 모니터 왼쪽 위 기준 상대 좌표를 DB 설정 `live_draw_toolbar_pos`(JSON `[x, y]`)에 쓴다. 켤 때 값이 있으면 그 자리, 판서 창 안으로 잘라 넣는다(해상도가 다른 모니터에서도 화면 밖으로 안 나감). 없으면 지금처럼 아래 가운데 | 모니터마다 따로 기억 · 비율로 기억 | 물어서 정함(기억하기) · 자리 방식은 Claude가 정함 · 판서 창은 DB를 모르므로 시그널 `toolbar_moved(x, y)`로 앱이 쓴다(`live_draw_last_tool` 선례 `pasteflow/app/live_draw.py`) |
| 연필 아이콘 반투명 | 앱 쓰기 상태의 「판서 중」 연필 아이콘이 평소 불투명도 0.45, 마우스를 올리면 1.0, 떼면 0.45(`setWindowOpacity`) | 끈 뒤 Ctrl+Z 안내(사용자가 고르지 않음) | 물어서 정함 · `pasteflow/ui/live_draw_badge.py` |

## 1. 지금 상태

- 공용 툴바 `_EditorMixin._build_toolbar`(`pasteflow/ui/image_annotator.py`)의 도구·되돌리기·새 칠판·복사·저장 버튼이 모두 `setIconSize(QSize(18, 18))`. 아이콘 그림 `_tool_icon`은 22×22 그림이라 22px에서도 흐리지 않다. 새 칠판 아이콘은 `annot_icon("trash", 색)`(크기 인수 기본 18, `pasteflow/ui/annot_icons.py`).
- 판서의 앱 쓰기 버튼 `pasteflow/ui/live_draw.py:161` `QSize(18, 18)`.
- 툴바 자리: `start`(`pasteflow/ui/live_draw.py:180`)가 늘 모니터 아래 가운데(`_TOOLBAR_BOTTOM_GAP`, `pasteflow/ui/live_draw.py:30`)로 옮긴다. 손잡이 `_ToolbarGrip`의 `mouseReleaseEvent`(`pasteflow/ui/live_draw.py:105`)는 끌기만 끝낸다. 자리를 저장하는 곳은 없다(`toolbar_pos`를 `pasteflow/`에서 찾아 0건).
- 연필 아이콘 `LiveDrawBadge`(`pasteflow/ui/live_draw_badge.py`)는 늘 불투명(배경 알파 220). 마우스 올림 처리 없음(`enterEvent` 0건).

## 2. 원하는 동작

1. 판서를 켜면 툴바 아이콘이 지금보다 크다(22px). 미리보기 편집기(Space) 툴바는 그대로.
2. 판서 툴바를 손잡이로 옮겨 놓고 끈 뒤 다시 켜면 그 자리에 툴바가 있다. 앱을 껐다 켜도 같다. 다른 모니터(해상도가 다름)에서 켜도 화면 안에 보인다.
3. 처음(저장값 없음)이나 저장값이 깨졌으면 아래 가운데.
4. 앱 쓰기 상태에서 오른쪽 위 연필 아이콘은 흐리게 보이고, 마우스를 올리면 진해진다. 누르면 그리기로(지금과 같음).
