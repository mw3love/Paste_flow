주석 편집기(판서·이미지 미리보기 편집 공용)의 도구 옵션창(미니패널)을 다시 그린다. 시안 비교 페이지 https://claude.ai/artifact/W84WyF27hAup3TmNyCjisy (S0 지금 모습, S1·S2·S3 시안, 여는 방법 F1·F2)에서 사용자가 고른 것: S2 좋음, F2 좋음(F1 애매). 시안 그림을 만든 스크립트는 세션 임시 폴더에 있었고 저장소에는 없다 — 그림 모양은 아래 2칸 글이 기준이다.

## 1. 지금 상태

- 도구 버튼 누름: `btn.clicked` → 켜진 도구면 `set_tool(None)`, 아니면 그 도구(`pasteflow/ui/image_annotator.py:2807`). 그리기 도구는 우클릭 → `_show_tool_settings`(`pasteflow/ui/image_annotator.py:2876`)가 패널을 토글하고 버튼 가운데 위 4px에 둔다.
- 패널 만들기 `_build_tool_settings_popup`(`pasteflow/ui/image_annotator.py:2911`): 어두운 스타일, 모양 줄(도형), `_StrokePreview`(`pasteflow/ui/image_annotator.py:2551`), 색 네모 칸 7개 + 스포이드, 굵기 점(`_WIDTH_DOTS`·`_MARKER_WIDTH_DOTS`, `pasteflow/ui/image_annotator.py:2533`) + 라벨 없는 두께 슬라이더, 화살표는 머리 슬라이더(`_set_arrow_head_size`, `pasteflow/ui/image_annotator.py:3112`)와 방향 버튼(`_toggle_arrow_dir_panel`, `pasteflow/ui/image_annotator.py:3119`), 텍스트·번호는 크기 슬라이더(`_build_slider_row`, `pasteflow/ui/image_annotator.py:3065`). 패널 창 클래스는 `_ToolSettingsPopup`(`pasteflow/ui/image_annotator.py:2571`, 그랩 없는 Tool 창), 닫기는 `_hide_tool_popups`(`pasteflow/ui/image_annotator.py:2904`).
- 툴바 스타일은 `pasteflow/ui/image_preview.py`의 `_CHROME_QSS`(밝은 알약 `#f4f4f4`·`#cfcfcf`, 눌림 `#cfe3ff`).
- 도구 버튼 위 휠은 지금 아무 일도 안 한다(버튼에 휠 처리 없음 — `wheelEvent`·`eventFilter` 검색함).

## 2. 원하는 동작

### 옵션창 모양

- 밝은 상자, 연 버튼 가운데를 가리키는 아래 꼬리(7px). 상자는 버튼 가운데 위에 두고, 화면 밖으로 밀리면 상자만 옮기고 꼬리는 버튼을 계속 가리킨다(상자 안쪽 14px까지).
- 색 칸: 지름 16px 원, 고른 색은 바깥 2px `#3a3a3a` 고리. 흰색 칸은 옅은 회색 테두리.
- 슬라이더 줄: 라벨(「두께」·「크기」, `#6b6b6b` 12px) · 슬라이더(지금 값까지 진한 색, 손잡이 원) · 숫자 · 실제 크기 점(지금 색, 지름 = 값, 22px 칸에서 넘치면 칸 크기).
- 눌린 버튼(모양·머리 단계) 바탕은 툴바와 같은 `#cfe3ff`.
- 형광펜의 실제 크기 점은 반투명(형광펜 알파)으로.

### 열고 닫기

- 그리기 도구(형광펜·펜·도형·화살표·텍스트·번호·사라지는 펜): 꺼진 버튼을 누르면 도구만 켠다. 켜진 버튼을 누르면 옵션창 열기, 열린 채 누르면 닫기. 우클릭은 지금처럼 열기·닫기.
- 도형 버튼: 키 4 순환·옵션창의 모양 고르기는 지금 그대로. 버튼을 다시 누르면 옵션창(모양을 바꾸지 않음).
- 선택 도구: 켜진 채 다시 누르면 도구 없음(지금 그대로).
- 캔버스를 누르거나 도구를 바꾸면 옵션창이 닫힌다(지금 `_hide_tool_popups` 자리 그대로).

### 버튼 위 휠

- 그리기 도구 버튼 위에서 휠 한 칸 → 그 도구 옵션창을 연다(다른 도구 창은 닫음) → 슬라이더 값 ±1(범위 안) → 열린 창의 숫자·점이 바로 바뀐다. 값은 지금처럼 도구 기본값에 저장된다(DB `annot_tool_defaults`).
- 판서 창: 툴바 위 휠은 아래 창으로 넘기지 않는다(지금과 같음 — 판서 조작 개선 문서의 알려진 한계).
