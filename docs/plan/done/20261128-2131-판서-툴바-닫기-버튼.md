## 1. 지금 상태

- 판서 툴바 호스트 줄: 손잡이 → 공용 툴바(`_build_toolbar`) → 구분선 → 「앱 쓰기」 버튼(`pasteflow/ui/live_draw.py:159`부터 `pasteflow/ui/live_draw.py:165`까지, `NoFocus`).
- 끄기는 `hide_board`(Esc는 `_on_escape`, 단축키는 `pasteflow/app/live_draw.py:51` `_on_live_draw_hotkey`).
- 툴팁에 쓸 단축키 글자 만들기 `_pretty_hotkey`(`pasteflow/app/live_draw.py`), 설정 키 `hotkey_live_draw`.
- 판서 툴바에 닫기 버튼은 없다(`close`를 `pasteflow/ui/live_draw.py`에서 찾아 버튼 0건).

## 2. 원하는 동작

1. 판서를 켜면 툴바 맨 오른쪽에 X 버튼이 보인다(앱 쓰기 버튼 오른쪽).
2. 마우스를 올리면 툴팁 「끄기 (Ctrl+Shift+D) — 다시 켜면 빈 칠판, Ctrl+Z로 지난 그림」. 설정에서 단축키를 바꾸면 툴팁 글자도 그 키.
3. 누르면 판서가 꺼진다(Esc·단축키와 같음). 다시 켜면 빈 칠판, Ctrl+Z로 직전 그림.
4. 버튼은 키보드 포커스를 가져가지 않는다(`NoFocus` — 가져가면 Esc가 뷰를 안 거친다).
