# 커밋 직전 검사와 순차 붙여넣기 규칙 시험을 깔아 이후 구조 변경의 안전망을 만든다

상태: 초안
만든 날: 2026-11-16 11:30

## 지금 무엇이 불편한가

리모델링 진단(`docs/remodel/20261116-진단.md`)에서 사용자가 「바꾼다」로 판정한 칸(2026-11-16). 언어는 파이썬 유지 — 이 일은 파이썬 안에서 한다. 순서: 시험과 검사 → 이미지 파일 저장 → 폴더 구조(앞 일이 뒤 일의 안전망).

시험 148개는 있지만 핵심인 `pasteflow/paste_interceptor.py`(1,147줄)·`main.py`·화면은 시험이 없다. 커밋 직전 검사 훅·타입 검사·린트·파일 길이 검사가 없다. 순차 붙여넣기는 과거 두 번 실패한 지점인데 규칙을 기계가 지키지 않는다.

## 원하는 동작

- 커밋 직전 검사: 전역 틀(`~/.claude/hooks/commit-gate-hook.py` + 프로젝트 `.claude/commit-gate.json`, Easy CAD 선례)을 붙여 커밋할 때 `pytest`가 돌고 실패하면 막는다.
- 순차 붙여넣기 규칙(10초 · 평범한 Ctrl+V · 자체 쓰기 무시 · 소진 뒤 개입 안 함 · 붙여넣기 중 새 복사)을 임의 순서 사건으로 두드리는 상태 조합 시험(속성 기반, hypothesis 후보).
- 파일 길이 검사(새 파일 300줄 경고 등 — 기존 큰 파일은 예외 목록으로 시작).
- 타입 검사(pyright 기본 단계) — 처음엔 보고만, 실패로 치지 않음(후보).

## 어떻게 되면 끝인가

커밋할 때 시험이 자동으로 돌고 실패하면 커밋이 막힌다. 순차 붙여넣기 규칙 시험이 생겨 통과한다. 파일 길이 검사가 돈다.

## 하지 않는 것

- 메모장 통합 시험(진짜 키 입력) — 사용자 데스크톱에서 돌아야 해서 별도 판단.
- 기존 코드 고치기(시험이 버그를 찾으면 보고만, 고치기는 따로).

## 정해 둔 것 · 모르는 것

- 정해 둔 것: 언어 유지 · 이 일이 가장 먼저.
- 모르는 것: 타입 검사를 실패로 칠지 · 파일 길이 기준 숫자 · `.gitignore`가 `.claude/`를 통째로 빼고 있어 `.claude/commit-gate.json`을 어떻게 커밋할지(지금 `.gitignore`에 `.claude/` 줄이 있음).
