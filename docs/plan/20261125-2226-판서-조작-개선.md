## 1. 지금 상태

- 판서 창 `LiveDrawOverlay`(`pasteflow/ui/live_draw.py`): `start`(`pasteflow/ui/live_draw.py:136`)가 늘 `set_tool("pen")`으로 시작한다(`pasteflow/ui/live_draw.py:144`). 휠은 뷰의 `wheelEvent`(`pasteflow/ui/image_annotator.py:2020`)가 그림 위 Shift+휠이 아니면 호스트 `_on_wheel_zoom(dy)`를 부르는데, 판서 창은 아무것도 안 한다(`pasteflow/ui/live_draw.py:236`).
- 클릭 통과 켜고 끄기는 `pasteflow/winapi/click_through.py`의 `set_click_through(hwnd, on)`. 마우스 입력 주입 구조체(`MOUSEINPUT`)와 `SendInput` 사용 선례는 `pasteflow/paste_interceptor.py:81`과 `pasteflow/winapi/drag_paste.py`에 있다. 휠 주입(`MOUSEEVENTF_WHEEL`)은 아직 아무 데도 없다(검색함).
- 앱 쓰기 상태 칩은 `LiveDrawMixin._on_live_draw_mode`(`pasteflow/app/live_draw.py:31`)가 `ToastNotification`(지속형, 클릭 통과)으로 띄우고 `_dismiss_live_draw_chip`이 닫는다. 칩 글의 단축키는 `_pretty_hotkey`(`pasteflow/app/live_draw.py:12`).
- 판서 창이 닫히면 `closed` 시그널 → `_on_live_draw_closed`(`pasteflow/app/live_draw.py:49`)가 칩을 닫고 `_live_draw`를 비운다. 켜기는 `_on_live_draw_hotkey`(`pasteflow/app/live_draw.py:17`)가 창을 만들고 `ov.start()`를 부른다(`pasteflow/app/live_draw.py:29`).
- 메뉴 아이콘 `pencil-simple`(Phosphor 듀오톤 SVG)이 `pasteflow/ui/menu_icons.py`에 있고 `menu_icon(name, color, disabled_color)`(`pasteflow/ui/menu_icons.py:43`)로 `QIcon`을 만든다.
- DB 설정 읽기·쓰기는 `get_setting`·`set_setting`(`pasteflow/database.py:531`·`pasteflow/database.py:539`).

## 2. 원하는 동작

### 휠

- 판서 그리기 상태에서 휠을 돌리면 커서 아래 앱이 평소처럼 스크롤된다(크롬·메모장·탐색기 등). 판서 창의 포커스·그림·툴바는 그대로다.
- 순서: 판서 창이 휠을 받으면(그림 위 Shift+휠이 아닐 때) 클릭 통과를 켜고(이미 켜 둔 상태면 그대로), 받은 휠 양(`dy`)을 `SendInput`의 `MOUSEEVENTF_WHEEL`로 다시 넣는다. 타이머(메인 스레드 `QTimer`, 100ms, 휠마다 다시 시작)가 끝나면 클릭 통과를 끈다. 그 0.1초 사이에 누른 클릭은 아래 앱으로 간다(스크롤 중이라 무방).
- 타이머가 끝나기 전에 앱 쓰기 상태로 바뀌거나 창이 닫히면 타이머를 멈추고 그 상태의 클릭 통과 값을 따른다(앱 쓰기면 켜진 채, 닫히면 상관없음). 그리기로 돌아올 때(`_enter_draw`)는 지금처럼 클릭 통과를 끈다.
- 다시 넣은 휠이 판서 창에 또 들어오면(클릭 통과가 아직 안 먹은 경우) 무한 반복이 되므로, 주입 중 표시를 두고 그동안 들어온 휠은 다시 넣지 않는다.
- 미리보기 편집기의 휠(확대)은 바뀌지 않는다.

### 켤 때 도구

- 판서를 닫을 때(Esc·앱 종료 포함) 그때 도구 이름을 `live_draw_last_tool`에 쓴다(도구 없음이면 빈 글자).
- 켤 때 그 값이 지금 판서 도구 표(도구 정리 문서의 1부터 8 — 선택·형광펜·펜·도형의 rect·ellipse·화살표·텍스트·번호·사라지는 펜)에 있으면 그 도구로, 아니면 펜으로 시작한다.

### 「판서 중」 아이콘

- 앱 쓰기 상태가 되면 판서 모니터의 사용 가능 영역 오른쪽 위(오른쪽·위 12px 띄움)에 지름 36px 원을 띄운다. 바탕은 `#121212`에 알파 220, 가운데에 코랄(`PEACH`) 연필 아이콘 20px.
- 창 성질: 테두리 없음·작업 표시줄에 안 나옴·맨 위(`Tool`+`StaysOnTop`)·나타날 때 포커스를 뺏지 않음(`WA_ShowWithoutActivating`)·클릭은 받음. 띄운 뒤 판서 창보다 위에 오게 `claim_topmost`를 건다.
- 마우스를 올리면 손가락 커서, 툴팁 「판서 중 — 누르면 그리기 (Ctrl+Shift+D)」(단축키는 설정값을 `_pretty_hotkey`로).
- 누르면(왼쪽 버튼을 뗄 때) 판서 창의 `toggle_mode`로 그리기 상태가 된다 — 툴바가 나오고 아이콘은 사라진다(지금 칩이 그리기로 돌아올 때 사라지는 것과 같은 길).
- 그리기 상태로 돌아올 때·판서를 닫을 때·앱을 끝낼 때 아이콘을 닫는다(지금 칩과 같은 자리).
