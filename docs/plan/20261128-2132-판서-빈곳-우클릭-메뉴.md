## 1. 지금 상태

- 뷰의 우클릭은 그림 위면 `_open_item_settings_at`(`pasteflow/ui/image_annotator.py:2506`)이 옵션창을 연다. 빈 곳은 아무것도 안 한다.
- 공용 우클릭 메뉴 `make_menu`(`pasteflow/ui/menu_style.py`)가 있다 — 재사용 후보.
- 후보 항목: 복사·저장 | 새 칠판·앱 쓰기 | 끄기.

## 2. 원하는 동작

1. 판서 그리기 상태에서 빈 곳 우클릭 → 메뉴가 커서 자리에 뜬다.
2. 메뉴의 복사·저장은 툴바 버튼과 같다.
3. 그림 위 우클릭은 지금처럼 옵션창.
