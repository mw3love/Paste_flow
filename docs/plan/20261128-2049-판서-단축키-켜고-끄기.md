## 1. 지금 상태

- 단축키 슬롯 `LiveDrawMixin._on_live_draw_hotkey`(`pasteflow/app/live_draw.py:44`): `self._live_draw`가 있으면 `ov.toggle_mode()`(그리기와 앱 쓰기 전환), 없으면 커서 모니터의 칠판을 `board_action`으로 골라 `reopen()`하거나 새로 만들어 `start()`.
- `self._live_draw`는 보이는 판서 창이다. 숨기면 `hidden` 시그널 → `_on_live_draw_hidden`(`pasteflow/app/live_draw.py:95`)이 아이콘을 닫고 도구를 저장하고 `None`으로 비운다. 숨긴 창은 `_live_draw_boards`(`pasteflow/main.py:200`)에 남는다.
- 판서 창 `LiveDrawOverlay`: `toggle_mode`(`pasteflow/ui/live_draw.py:176`), `_enter_draw`(`pasteflow/ui/live_draw.py:182` — 클릭 통과 끄기·툴바 보이기·포그라운드·`mode_changed(True)`), `_enter_pass`(`pasteflow/ui/live_draw.py:198` — 텍스트 확정·패널 정리·툴바 숨김·클릭 통과 켜기·앞 창 포그라운드·`mode_changed(False)`), `hide_board`(`pasteflow/ui/live_draw.py:163`), `reopen`(`pasteflow/ui/live_draw.py:157` — `show` 뒤 `_enter_draw`, 그림은 그대로).
- 툴바 호스트: `_ToolbarGrip` 다음에 공용 툴바 레이아웃(`bar.addLayout(self._build_toolbar())`, `pasteflow/ui/live_draw.py:132`). 앱 쓰기 버튼은 없다(「앱 쓰기」·`passthru`를 `pasteflow/ui/`에서 찾아 툴팁·버튼 0건).
- 연필 아이콘: `_on_live_draw_mode`(`pasteflow/app/live_draw.py:71`)가 `mode_changed(False)`에 `LiveDrawBadge`를 띄우고, 클릭은 `_on_live_draw_badge_clicked`(`pasteflow/app/live_draw.py:83`)가 `toggle_mode()`로 그리기로 돌린다.
- 「새 칠판」의 `clear_board`(`pasteflow/ui/image_annotator.py:3592`)는 최상위 그림을 모두 빼고 `push_undo_delete` 한 번으로 기록한다(그림이 없으면 기록 없음). 되돌리기 기록 `self._undo`는 창 객체에 남으므로 숨겼다 다시 열어도 Ctrl+Z가 된다.
- 툴바 아이콘 색 `_ICON_DARK`는 `pasteflow/ui/image_annotator.py`의 모듈 이름이다(공용 툴바 버튼이 `neutral_override=_ICON_DARK`로 씀, `pasteflow/ui/image_annotator.py:2942`).
- 설정창 판서 단축키 툴팁(`pasteflow/ui/settings_dialog.py:896`)은 「한 번 더 누르면 그림은 남긴 채 아래 앱을 쓰고, 또 누르면 다시 그립니다」·「Esc = 지우고 끝내기」 — 지금도 Esc 설명이 틀렸다(Esc는 숨기기).
- 시험: `tests/test_live_draw_prefs.py`(`pick_start_tool`·`board_action`).

## 2. 원하는 동작

1. 판서가 꺼져 있을 때 Ctrl+Shift+D → 커서 모니터에 판서가 켜지고 그리기 상태(지금과 같음). 전에 그 모니터에서 그린 그림이 있었어도 화면은 비어 있다.
2. 비어 있는 채로 Ctrl+Z → 직전에 끌 때 있던 그림이 한꺼번에 돌아온다. 한 번 더 Ctrl+Z → 그 전 그리기 동작이 되돌려진다(지금 되돌리기 그대로).
3. 그리기 상태에서 Ctrl+Shift+D → 판서가 꺼진다(Esc와 같음 — 쓰던 텍스트 확정, 앞 창 포커스). 연필 아이콘은 뜨지 않는다.
4. 그리기 상태에서 툴바 맨 오른쪽 「앱 쓰기」 버튼(툴팁 「앱 쓰기 — 그림은 두고 아래 앱 클릭 (연필 아이콘을 누르면 다시 그리기)」) → 지금 앱 쓰기와 같다: 툴바가 숨고 그림은 남고 클릭이 아래 앱으로 가고 오른쪽 위에 연필 아이콘.
5. 앱 쓰기 상태에서 연필 아이콘 클릭 → 그리기로 돌아온다(지금과 같음).
6. 앱 쓰기 상태에서 Ctrl+Shift+D → 판서가 꺼지고 연필 아이콘도 사라진다. 다음에 켜면 1번처럼 빈 칠판.
7. 그리기 상태의 Esc는 지금처럼 숨기기. Space는 지금처럼 아무것도 안 함.
8. 설정창 「캡처·녹화」의 판서 단축키 툴팁이 새 동작을 말한다: 누르면 켜고 한 번 더 누르면 끈다 · 툴바 「앱 쓰기」 버튼 · 다시 켜면 빈 칠판(Ctrl+Z로 지난 그림) · Ctrl+C 캡처 · Esc 끄기.

### 구현 메모

- `hotkey_action(visible: bool) -> str` — 보이는 판서가 있으면 `"hide"`, 없으면 `"open"`. `_on_live_draw_hotkey`는 `"hide"`면 `ov.hide_board()`를 부른다(앱 쓰기 상태여도 같은 함수 — `hidden` 시그널이 아이콘을 닫는다).
- 앱 쓰기 상태에서 숨길 때 창이 클릭 통과인 채 숨는다. 다시 열 때 `reopen`이 부르는 `_enter_draw`가 클릭 통과를 끄므로 따로 손대지 않는다.
- 앱 쓰기 상태에서 숨길 때는 `hide_board`가 앞 창 포커스를 돌려주지 않는다(`self._drawing`이 거짓이면 `_give_back_foreground`를 건너뜀). 앱 쓰기 동안 사용자가 다른 앱으로 옮겼을 수 있는데, `_prev_fg`는 그리기로 들어올 때 기억한 옛 창이라 그리로 포커스가 튄다(`pasteflow/ui/live_draw.py:173`, `pasteflow/ui/live_draw.py:186`). 그리기 상태의 숨기기(Esc·단축키)는 지금처럼 돌려준다.
- `reopen`은 `show()` 전에 `self.clear_board()`. `start`(새 창)는 그림이 없으니 부르지 않는다.
- 「앱 쓰기」 버튼은 `QToolButton`(아이콘 18px, 공용 툴바 버튼과 같은 크기) — 누르면 `self._enter_pass()`. 아이콘은 `live_draw.py` 안 작은 함수가 `QPainter`로 마우스 화살표 다각형을 그린 `QIcon`(DPR 반영). 버튼 앞에 공용 툴바와 같은 모양의 세로 구분선을 둔다(`self._vsep()`).
- `toggle_mode`는 단축키가 더는 부르지 않는다. 연필 아이콘 클릭이 계속 쓰므로 지우지 않는다.
- `live_draw.py`는 이미 300줄을 넘는 기존 파일이라 길이 검사에서 목록만 나온다. 아이콘 그리기를 넣어 많이 길어지면 `pasteflow/ui/live_draw_badge.py` 쪽에 두어도 된다.
